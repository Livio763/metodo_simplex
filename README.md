# Método simplex

Presentación local del método simplex para Métodos Numéricos, MAT 205-SC. Explica el modelo del informe y resuelve la tabla pivote a pivote. También deja cambiar el modelo en vivo.

Corre en la computadora de quien expone. Después de instalar, no hace falta internet.

## Cómo correrlo

Hace falta Node.js 20 o más nuevo. npm viene con Node.

```bash
git clone https://github.com/wdiegow/metodo-simplex.git
cd metodo-simplex
npm install
npm run dev
```

Abre http://127.0.0.1:5173

Para parar el servidor, `Ctrl+C` en esa terminal.
